# 파닉스 리딩

6세 아이가 혼자 푸는 파닉스 퀴즈 웹앱. 지금은 **기본 틀만** 있고, 문제 유형은 학습지를 보고 정한 뒤 추가해요.

| 파일 | 하는 일 | 언제 바뀌나 |
|---|---|---|
| `index.html` | 화면 모양 | 거의 안 바뀜 |
| `app.js` | 공통 기능: 4개 카테고리, 퀴즈 엔진(힌트·오답·쉬운 문제·소리 실패·쉬기), 기록, 백업 | 거의 안 바뀜 |
| `modules/` | 문제 유형 (승인된 것만) | 문제 유형을 정할 때 |
| `words.js` | 학습 콘텐츠: 배운 소리, 단어, 문장, 승인된 문제 유형 | 매일 |
| `audio/manifest.js` | 음원 목록 | 음원이 생길 때 |

`?test=1`을 주소 뒤에 붙이면 시험용 문제가 나와요 (개발 확인용).

아이 이름, 사진, 학습 기록, 책 사진은 이 저장소에 올리지 않아요.
